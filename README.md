# SDEV245 — Security and Secure Coding
This repository contains my coursework, demos, and projects for Ivy Tech’s
SDEV245: Security and Secure Coding. The class focuses on understanding common
software vulnerabilities, how attackers exploit them, and how to write code
that avoids those issues.

## Course Topics
Throughout the semester, we cover:
- Secure coding principles
- Encryption (symmetric and asymmetric)
- Hashing and data integrity
- Input validation and sanitization
- Common vulnerabilities (SQL injection, XSS, buffer overflows)
- Authentication and access control
- Secure software development lifecycle (SSDLC)
- Basic threat modeling

## Repository Contents
This repo includes:
- Weekly assignments and exercises
- Small demo programs (Python and/or Java)
- Encryption/Decryption examples
- Notes and reference materials
- Any project files required for the course

Each assignment folder contains:
- Source code
- A README or explanation of the task
